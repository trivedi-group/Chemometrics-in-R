# chemometrics
Chemometrics DL interactive course is designed for The University of Manchester students.

# installing swirl

Open RStudio (or just plain R if you don't have RStudio) and type the following into the console:
> install.packages("swirl")

# installing chemometrics course

The first time you start swirl, you'll be prompted to install a course. You can install one of the recommended courses following these steps.
All the courses for this unit are found at: https://github.com/drupadt/Chemometrics_DL 

1.	Go to Github link https://github.com/drupadt/Chemometrics_DL \
2.	Locate the green button that says “Code” and click on it.
3.	When you click on the “Code” button, you will see a dropdown menu. 
4.	Click on Download Zip (the last option) from the dropbox menu.
5.	The zip file will download in Documents/Downloads folder of your Windows/Mac/Linux machine depending on your browser settings. 
6.	Locate the zip and move it to Desktop
7.	Now you are ready to install this course in R. 
8.  In your R console, write the following command and hit enter:
> install_course_zip(file.choose())
 
9.	You will see a file chooser window pop-up. Select Chemometrics_DL-main.zip that you moved to Desktop.
10.	Now assuming you have already installed swirl, type the following in console and 

> library(swirl)
> swirl()

11. * When it asks you " Welcome to swirl! Please sign in. If you've been here before, use the same name as you did then. If you are new, call yourself something unique."
Type back your name and hit enter.

12. * On being prompted with the following question, follow the prompts to launch course “Chemometrics_DL-main”:
> | Please choose a course, or type 0 to exit swirl.

13.	Once you have successfully launched the course, you will be prompted to select a lesson you want to work through. Choose recommend lesson topic and work through the lesson at your own pace.

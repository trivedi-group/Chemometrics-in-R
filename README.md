# chemometrics
Chemometrics DL interactive courses

# installation
* install.packages(swirl)
* library(swirl)
* install_course_github("drupadt", "Chemometrics_DL")

# execution
* In R console, type:

> swirl()

* When it asks you " Welcome to swirl! Please sign in. If you've been here before, use the same name as you did then. If you are new, call yourself something unique."
Type back your name and hit enter.

* On being prompted with the following question:
| Please choose a course, or type 0 to exit swirl.
Choose : Chemometrics DL

* Follow the prompts.
